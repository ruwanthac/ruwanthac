## Featured Projects

### 🚗 [RideGuide](https://github.com/ruwanthac/RideGuide): AI Vehicle Diagnosis & Roadside Assistance Platform
Full-stack platform for vehicle diagnosis and roadside assistance requests, with real-time provider matching and messaging.
- JWT authentication with role-based access control
- Real-time features using Socket.IO
- API testing with Jest and Supertest

`React` `React Native` `TypeScript` `Node.js` `Express` `MongoDB` `Socket.IO` `JWT` `Jest`

### 📅 [Service Booking API](https://github.com/ruwanthac/service-booking-api)
Modular REST API with booking validation, duplicate prevention, status workflow and cancellation rules.
- Controller / service / DTO architecture with search, filtering and pagination
- Prisma migrations and relations on PostgreSQL, local setup via Docker Compose
- Documented with Swagger/OpenAPI, including JWT bearer auth

`NestJS` `TypeScript` `PostgreSQL` `Prisma` `Swagger` `Docker`

### 🍔 [QuickBite](https://github.com/ruwanthac/QuickBite): Restaurant Ordering & Management System
Responsive full-stack ordering system with an admin dashboard for products, users and orders.
- Role-based access control and secure authentication
- API security with Helmet, CORS and rate limiting

`React` `Node.js` `Express` `MongoDB` `Tailwind CSS` `JWT`

### 💊 [Prescription Analysis API](https://github.com/ruwanthac/PrescriptionAnalysisAPI)
REST API that converts unstructured prescriptions into structured JSON, with validation and error handling.

`C#` `Node.js` `REST` `JSON` `Postman`

### 🛒 [HotWheelsHub](https://github.com/ruwanthac/hotwheelshub): E-commerce Website
Responsive e-commerce app with authentication, shopping cart and reusable UI components.

`React` `Firebase` `Firestore` `Tailwind CSS`
